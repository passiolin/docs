# 巡检报告(reports)

> - **命名规则**:`类型-YYYYMMDD.md`,`类型` 与 [skills/巡检](../../skills/巡检/README.md) 下的 skill 同名(`inspect-ac`、`inspect-server`、`inspect-middleware`)。一天跑多次就覆盖同一份文件,以文末「全量清单」的时间戳为准。
> - **报告性质**:一次巡检一份,只读采集,不改动被检对象。逐项结论、异常项、全量清单三块齐全才算完整。
> - **不放正文**:巡检的判定标准与阈值写在对应 skill 里,报告只记录这一次的结果和当时的异常。

## 阅读方式

报告顶部三行给出对象、方式、结论,要判断"这次值不值得细看"看这三行就够。异常项为空时,直接跳到「全量清单」核对采集范围,确认巡检真的跑过而不是中途失败。
