# lark2didi

飞书通讯录到滴滴企业版的组织架构同步服务。飞书是人员与部门的主数据源，服务每小时同步新增员工、部门树、部门主管、人员归属和离职状态；写操作不调用滴滴删除接口。

> - **版本基线**：Python 3.12+，服务器 3.14.4；飞书企业自建应用 + 滴滴企业版开放平台企业内部应用；2026-11-06 上线，2026-11-23 更新。
> - **运行位置**：`<SYNC_SERVER_IP>:/opt/lark2didi`，出口 IP `<PUBLIC_EGRESS_IP>`，root crontab 每小时执行。
> - **当前规模**：飞书 12 个部门、50+ 人；滴滴 13 个成本中心，在职人员全部归入部门，离职人员保留在根成本中心。

## 组件说明

同步服务是独立 Python 程序，不依赖数据库；状态文件落在本机 `state/`，审计日志按天写 `logs/`。飞书侧只做通讯录读取，滴滴侧只做新增、修改归属、设置离职时间，不删除员工和部门。
