## 这个目录在讲什么

主机层是中间件的地基:文件描述符不够,ES 起不来;conntrack 表满,新连接被内核悄悄丢掉;swap 没配,小内存机器 OOM 来得毫无征兆。这套文档按「到手即做」的顺序排,每条命令都带实测输出,不写教科书式的原理铺陈。
