## 这个目录在讲什么

nginx 在这套环境里不是 Web 服务器,而是 MQTT 的 L4 入口:一条客户端连接对应一条到 broker 的上游连接,nginx 只做字节转发。连接数上到几十万后,参数问题会让位给宿主算力问题——`worker_connections` 和 fd 是入场券,心跳包过虚拟化路径的软中断才是天花板。第 1 篇用 80 万连接的实测数据把这条边界画出来。
