# 9. 监控与告警

## 分工:巡检(命令面)与监控(指标面)用同一套 R 编号

| 巡检项 | 命令面 | 指标面(实测指标名) | 阈值(同源巡检) |
| --- | --- | --- | --- |
| R01 存活 | PING | `redis_up` | 0 = P0 |
| R02/R03 内存 | INFO memory | `redis_memory_used_bytes` / `redis_memory_max_bytes` | used/max > 0.8 P1 / > 0.95 P0 |
| R05 碎片率 | INFO memory | used_rss/used(exporter: `redis_memory_used_rss_bytes`) | >2 P1 / >3 P0(used≥100MB 才判) |
| R06 命中率 | INFO stats | `redis_keyspace_hits_total` / `redis_keyspace_misses_total` | <90% P2 / <80% P1 |
| R07 持久化 | INFO persistence | `redis_rdb_last_bgsave_status`(1=ok) | ≠1 P1 |
| R08 拒绝连接 | INFO stats | `redis_rejected_connections_total` | 增长 P1 |
| R09 淘汰 | INFO stats | `redis_evicted_keys_total` | 增长 P1 |
| R10 阻塞客户端 | INFO clients | `redis_blocked_clients` | 持续 >0 P1 |
| R11 复制 | INFO replication | `redis_master_link_up{master_host=...}` | 0 P1 |
| R12 慢命令 | SLOWLOG | `redis_slowlog_length` | 增长 P2 |
| R13 趋势 | INFO stats | `rate(redis_commands_processed_total[5m])` | 超基线 2 倍 P2 |

`redis_instance_info{role=...,redis_mode=...,maxmemory_policy=...}` 一个指标带出角色/模式/策略,适合作面板标签。

## exporter 部署(实测)

```bash
docker run -d --name redis-exporter --restart=always --net=host \
  -e REDIS_ADDR=redis://127.0.0.1:6379 \
  -e REDIS_PASSWORD=Redis@2026 \
  oliver006/redis_exporter:v1.66.0
# 验证:curl -s localhost:9121/metrics | grep -c '^redis_'  → 451
```

- 每实例一个 exporter(host 网络下 REDIS_ADDR 指本机实例);Cluster 每个 node 各一个或用 exporter 的 cluster 模式;
- redis_exporter 环境变量式配置,密码不进命令行参数(ps 不可见),比 redis-cli 的 -a 干净。

## 告警规则示例(与巡检阈值对齐)

```yaml
groups:
- name: redis
  rules:
  - alert: RedisDown                      # R01 / P0
    expr: redis_up == 0
    for: 30s
  - alert: RedisMemoryHigh                # R03 / P1,P0
    expr: redis_memory_used_bytes / redis_memory_max_bytes > 0.8
    for: 5m
  - alert: RedisEvicting                  # R09 / P1
    expr: rate(redis_evicted_keys_total[5m]) > 0
    for: 5m
  - alert: RedisBgsaveFailed              # R07 / P1
    expr: redis_rdb_last_bgsave_status != 1
    for: 1m
  - alert: RedisReplicaDown               # R11 / P1
    expr: redis_master_link_up == 0
    for: 1m
  - alert: RedisBlocked                   # R10 / P1
    expr: redis_blocked_clients > 0
    for: 5m
```

`redis_memory_max_bytes` 为 0(maxmemory 未设)时利用率除零——先修 R02 再谈 R03 的告警,与巡检的前置条件一致。
