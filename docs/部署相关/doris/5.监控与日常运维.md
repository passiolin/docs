# 5. 监控与日常运维

> **实测状态**:✅ 已实测 —— Doris 2.1.7,2026-09-30。FE/BE 自带 metrics 端点实测可用;排障字典来自本实验实录。

## 监控:自带 metrics 端点(零部署)

```bash
curl -s http://<FE>:8030/metrics     # FE 指标(实测 317 个 doris_* 序列)
curl -s http://<BE>:8040/metrics     # BE 指标
```

实测 FE 端点样例:

```
# HELP doris_fe_qps query per second
doris_fe_qps 317
# HELP doris_fe_scheduled_tablet_num number of tablets being scheduled
doris_fe_scheduled_tablet_num 0
```

接入 Prometheus 直接 job 抓三个 FE + 三个 BE 的 /metrics 即可,无需额外 exporter。核心告警面(阈值起步值,按业务调):

| 指标面 | 来源 | 告警语义 |
| --- | --- | --- |
| FE 存活/角色 | `SHOW FRONTENDS`(或 http 探活 8030) | Alive!=true;无 IsMaster=true = P0 |
| BE 存活 | `SHOW BACKENDS` / be_http 8040 | Alive!=true P1;TabletNum = 0 持续 P2 |
| 查询时延 | doris_fe_query_latency* | 突增 P2 |
| 导入失败 | stream load 返回 Status!=Success | 按业务 P1 |
| tablet 调度 | doris_fe_scheduled_tablet_num 持续 >0 | 副本在补齐,观察 P2 |

## 日常操作速查

```bash
docker logs -f doris-fe / doris-be            # 服务日志(fe.log/be.log 也在挂载卷里)
docker run --rm mysql:8.4 mysql -h<FE> -P9030 -uroot -e "SHOW FRONTENDS; SHOW BACKENDS;"
docker run --rm mysql:8.4 mysql -h<FE> -P9030 -uroot -e "ADMIN SHOW REPLICA DISTRIBUTION FROM demo.events;"
```

## 排障字典(实测错误集)

| 报错/现象 | 根因 | 处置 |
| --- | --- | --- |
| `Please set vm.max_map_count to be 2000000` | 宿主内核参数 | 第 2 篇前置三件套 |
| `Please disable swap memory before installation` | swap 未关 | 同上 |
| `Set max number of open file descriptors ... 60000` | BE 容器句柄不足 | `--ulimit nofile=655350:655350` |
| `[ERROR] [Entrypoint]: EOF` 死循环 | FE 缺 FE_ID(或 FE_SERVERS 组合不对) | FE_SERVERS + FE_ID 成对 |
| FE 绑 172.17.0.1 | priority_networks 未生效 | conf 挂载显式设置 |
| `Node catalog is not ready` | FE 多数派不满足(2FE 丢 master / 选举中) | 第 4 篇冷启 Runbook;应用侧重试 |
| follower 容器日志刷 `registered to FE failed, retry` 但 JVM 不启动 | entrypoint 注册死锁(master 不在) | 第 4 篇绕法/冷启顺序 |
| BE 心跳通但 Alive 永远 false | FE 元数据重建后 cluster_id 不匹配 | 同步清 BE storage |
| 建表报 `no available BE nodes` | 无 Alive BE(或磁盘水位) | 先修 BE,再谈 DDL |
| Stream Load 全行失败,列数 1 | 默认分隔符是 TAB | `-H "column_separator:,"` |
| `start_fe.sh: fe.conf: No such file or directory` | conf 挂载源为空目录(docker cp 曾静默失败) | `test -f` 校验 + 重新提取 |
| BE 容器只剩 `entry_point.sh + sleep 15`、日志无新行、FE 心跳 BE 全拒 | init_be.sh 静默失败(错误被 `2>/dev/null` 吞),根因多是宿主前置回退(断电后 `vm.max_map_count` 实测打回 1048576) | 手工 `bash init_be.sh` 看真实报错;sysctl 落盘 /etc/sysctl.conf(第 4 篇冷启补充) |
| DECOMMISSION 报某表 replication > available backend | 内部表/恢复表副本数超过缩后台数 | 逐表降副本(动态分区表要 `default.replication_num`+`MODIFY PARTITION` 双改,第 4 篇缩容实录) |
