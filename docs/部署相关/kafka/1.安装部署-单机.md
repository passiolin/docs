# 0. 安装部署-单机

> **实测状态**:✅ 已实测 —— Kafka 4.3.1 单节点 KRaft(kafka-3 / 10.10.12.130,4C/4G),2026-10-01。单机即"自己选自己"的缩微集群:quorum 自举、topic、收发全验证。

## 什么时候用单机

开发/测试/边缘小场景(日流量 < 百万级消息)。单机 = 无副本无容错,数据面与集群形态完全同构——**将来加节点是演进不是重构**(拓扑变化见[第 2 篇](2.安装部署-KRaft集群.md))。

## 部署(实测命令)

单机与集群的差异只有三处:**仲裁选民只有自己、内部 topic 副本必须降为 1、advertised 写本机 IP**:

```bash
mkdir -p /data/kafka && chown -R 1000:1000 /data/kafka    # 容器 uid 1000(实测必须)
docker run -d --name kafka --restart=always --net=host \
  -e KAFKA_NODE_ID=1 \
  -e KAFKA_PROCESS_ROLES=broker,controller \
  -e KAFKA_CONTROLLER_QUORUM_VOTERS=1@10.10.12.130:9093 \
  -e KAFKA_CONTROLLER_LISTENER_NAMES=CONTROLLER \
  -e KAFKA_LISTENER_SECURITY_PROTOCOL_MAP=CONTROLLER:PLAINTEXT,PLAINTEXT:PLAINTEXT \
  -e KAFKA_INTER_BROKER_LISTENER_NAME=PLAINTEXT \
  -e KAFKA_LISTENERS=PLAINTEXT://:9092,CONTROLLER://:9093 \
  -e KAFKA_ADVERTISED_LISTENERS=PLAINTEXT://10.10.12.130:9092 \
  -e KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR=1 \
  -e KAFKA_TRANSACTION_STATE_LOG_REPLICATION_FACTOR=1 \
  -e KAFKA_TRANSACTION_STATE_LOG_MIN_ISR=1 \
  -e KAFKA_NUM_PARTITIONS=1 \
  -e "KAFKA_HEAP_OPTS=-Xmx1g -Xms1g" \
  -e KAFKA_LOG_DIRS=/var/lib/kafka/data \
  -e CLUSTER_ID=1SingleNodeClusterIDkafka1 \
  -v /data/kafka:/var/lib/kafka/data \
  apache/kafka:4.3.1
```

## 验证(实测输出)

```bash
docker logs kafka | grep "Kafka Server started"
# 单机 quorum:选民只有自己
timeout 60 docker exec kafka /opt/kafka/bin/kafka-metadata-quorum.sh \
  --bootstrap-server 127.0.0.1:9092 describe --status
# LeaderId: 1
# CurrentVoters: [{"id": 1, "endpoints": ["CONTROLLER://10.10.12.130:9093"]}]

timeout 60 docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server 127.0.0.1:9092 --create --topic single-test --partitions 1 --replication-factor 1
# Created topic single-test. / Partition: 0  Leader: 1  Replicas: 1  Isr: 1
```

收发与 lag 同集群形态(第 4 篇命令,bootstrap 换本机)。

## 单机 → 集群的演进路径

数据保留的话:按集群篇拉起新节点组网时把本机列为既有的 node.id=1 选民(拓扑参数对齐),**新节点直接加入既有元数据**;或单机只是试验田,集群全新建。生产切换前用 topic 数据迁移工具(未实测)。

## 已知坑(实测)

| 坑 | 现象 | 解 |
| --- | --- | --- |
| `-e KAFKA_HEAP_OPTS=-Xmx1g -Xms1g` 不加引号 | docker run 参数被空格拆断,容器建不起来 | `"KAFKA_HEAP_OPTS=-Xmx1g -Xms1g"` 整体引号 |
| RF 没降到 1 | 内部 topic(__consumer_offsets)副本数 > broker 数,消费者组报错 | 三个 *_REPLICATION_FACTOR=1 |
| 数据目录 root 属主 | crash 循环 AccessDeniedException | chown 1000:1000 |
