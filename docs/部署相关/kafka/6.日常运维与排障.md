# 6. 日常运维与排障

## 日常操作速查

```bash
B=10.10.12.128:9092
docker logs -f kafka                                    # broker/controller 日志
timeout 60 docker exec kafka /opt/kafka/bin/kafka-metadata-quorum.sh --bootstrap-server $B describe --status
timeout 60 docker exec kafka /opt/kafka/bin/kafka-topics.sh --bootstrap-server $B --list
timeout 60 docker exec kafka /opt/kafka/bin/kafka-consumer-groups.sh --bootstrap-server $B --list
timeout 60 docker exec kafka /opt/kafka/bin/kafka-log-dirs.sh --bootstrap-server $B --describe   # 磁盘占用(K07)
```

## 排障字典(实测错误集)

| 现象 | 根因 | 处置 |
| --- | --- | --- |
| 容器 crash 循环,日志 `AccessDeniedException: .../bootstrap.checkpoint.tmp` | `/var/lib/kafka/data` 宿主目录 root 属主 | `chown -R 1000:1000 /data/kafka` 后重启 |
| `executable file not found` | CLI 不在 PATH | 全路径 `/opt/kafka/bin/...` |
| 管道生产不报错但 offset 不涨 | `docker exec` 缺 `-i`,stdin 被丢 | 加 `-i` |
| CLI 卡住无输出 | JVM 慢启动/高负载 | timeout 包装;换 broker 再试;核进程而非重试命令 |
| ISR 长期 [单副本] | 副本节点掉线/磁盘慢 | 巡检 K04 P0 路径:先恢复节点,ISR 自动回满 |
| `Leader: none` 分区 | Leader 副本全灭 | K05 P0:优先触发 preferred election |
| 消费 lag 突增 | 消费者挂了/分区倾斜/大消息 | K02:增速+绝对值同看;`--describe` 找具体分区 |
| 建在 2 节点上的 RF=2 topic,重启一台后 under-replicated | 正常现象 | 回归后自动补齐;长期 under = K04 |
| 客户端连得上但收不到元数据 | advertised.listeners 配错 | 核对 node env 的真实 IP |

## 已知纪律(与前几篇互链)

- CLI 一律 timeout(第 2 篇);auto.create.topics 关闭后幽灵 topic 自然绝迹(第 3 篇);
- 老监控里的 ZK 2181 探活在 KRaft 下无意义,退役。
