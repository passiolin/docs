# 5. jmqtt-admin

> **实测状态**:✅ 已实测 —— jmqtt-admin main(0.1.0-SNAPSHOT),单镜像(前端打进 jar),2026-10-01。API 与 **UI 真浏览器验证**(登录、双节点视图)。

## 架构一句话

admin **不直连 broker**:读 Redis(broker 发布的状态),写 Redis 命令队列(broker 轮询执行)。部署上只需 Redis 可达 + key-prefix 与 broker 一致。

## 构建(docker 化工具链)

```bash
git clone --depth 1 https://github.com/passiolin/jmqtt-admin.git /opt/jmqtt-admin
# ① 前端(node 容器;受限环境有 nowasm 备用路径,见上游 README):
docker run --rm --net=host -v /opt/jmqtt-admin:/src -w /src/frontend node:20-slim \
  sh -c "npm ci --no-audit --no-fund && npm run build"
# ② dist 进 static 再打后端(= 上游 deploy/build.sh 的组装逻辑):
cp -r /opt/jmqtt-admin/frontend/dist /opt/jmqtt-admin/backend/src/main/resources/static
docker run --rm --net=host -v /opt/jmqtt-admin:/src -v /root/.m2:/root/.m2 -w /src/backend \
  maven:3.9-eclipse-temurin-21 mvn -q -B package -DskipTests
cp /opt/jmqtt-admin/backend/target/jmqtt-admin-backend-0.1.0-SNAPSHOT.jar /opt/jmqtt-admin/deploy/app.jar
cd /opt/jmqtt-admin/deploy && docker build -t jmqtt-admin:lab .
```

## 配置:上游 yml 无 env 占位(实测踩坑,重要)

**admin 的 application.yml 把笔者本机的 Redis Cluster(10.10.10.248:6379-6384)硬编码且无 `${}` 占位**——`JMQTT_ADMIN_REDIS_HOST` 这类 env 无效(与 broker 不同)。正确做法是 Spring 通用外部覆盖:

```yaml
# /data/jmqtt/admin-conf/overrides.yml(挂载为只读)
jmqtt:
  admin:
    redis:
      mode: standalone        # ★ standalone 模式认 host/port;只写 nodes 不生效(实测)
      host: 10.10.12.137
      port: 6379
      password: JmqttRedis@2026
      key-prefix: jmqtt       # ★ 与 broker 一致,配错不报错、表现为"一个节点都没有"
```

```bash
docker run -d --name jmqtt-admin --restart=unless-stopped -p 9100:9100 \
  -e TZ=Asia/Shanghai \
  -e SPRING_CONFIG_ADDITIONAL_LOCATION=file:/etc/jmqtt/overrides.yml \
  -v /data/jmqtt/admin-conf:/etc/jmqtt:ro \
  -v /data/jmqtt/admin-logs:/app/logs \
  jmqtt-admin:lab
```

## 验证(实测)

```bash
curl -s localhost:9100/actuator/health                      # {"status":"UP"}
# 登录换 token(注意路径是 /api/auth/login):
TOKEN=$(curl -s -X POST localhost:9100/api/auth/login -H 'Content-Type: application/json' \
  -d '{"username":"jmqtt","password":"jmqtt"}' | grep -o '"token":"[^"]*"' | cut -d'"' -f4)
curl -s localhost:9100/api/nodes -H "Authorization: Bearer $TOKEN"
# 实测:node-1/node-2 online:true,含 connections/sessions/topicNodes/clusterBusEnabled 全字段
```

**UI 实测(真浏览器)**:登录后"集群总览"显示 **在线节点 2/2**,node-1/node-2 卡片(连接/会话/订阅/心跳"刚刚"/MQTT-WS 端口),导航含客户端/主题/客户端驱逐/消息监听/性能指标;截图已归档。一个 UI 瑕疵如实记录:登录瞬间 overview 首次请求偶发"登录已过期"提示,轮询随即正常——数据最终正确,排查价值不高,上游可优化。

## 安全口径

- 默认账号 jmqtt/jmqtt、内存 token(重启全失效)——**内网管理台定位**,公网暴露必须前置反代 + TLS + 改默认密码;
- 9100 建议只绑内网/本机(同 broker 8922 的口径)。
