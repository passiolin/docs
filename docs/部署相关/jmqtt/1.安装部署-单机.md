# 1. 安装部署-单机

## 依赖拓扑

```
jmqtt-broker ── Redis(会话持久化 / admin 控制面;支持 standalone/sentinel/cluster)
             ── Kafka(集群总线 + 上行数据面;单机也建议开着,演进前置)
端口:1883 MQTT/TCP;8083 MQTT/WebSocket(/mqtt);8922 HTTP API + Actuator
```

**Kafka 前置(实测踩到)**:若 Kafka 按我们的基线关了自动建 topic,broker 起来后 consumer 会刷 `jmqtt-cluster=UNKNOWN_TOPIC_OR_PARTITION`——先手工建:

```bash
kafka-topics.sh --bootstrap-server <kafka> --create --topic jmqtt-cluster --partitions 3 --replication-factor 2
```

## 构建(docker 化工具链,宿主零安装)

```bash
git clone --depth 1 https://github.com/passiolin/jmqtt-broker.git /opt/jmqtt-broker
# ① jar(注意 finalName 是 jmqtt-broker.jar,不是带版本号的):
docker run --rm --net=host -v /opt/jmqtt-broker:/src -v /root/.m2:/root/.m2 -w /src \
  maven:3.9-eclipse-temurin-21 mvn -q -B package -DskipTests
cp /opt/jmqtt-broker/target/jmqtt-broker.jar /opt/jmqtt-broker/deploy/app.jar
# ② 镜像(deploy/Dockerfile,azul/zulu-openjdk 21 基础):
cd /opt/jmqtt-broker/deploy && docker build -t jmqtt-broker:lab .
```

镜像间分发:`docker save -o x.tar` → scp → `docker load -i`(实测直接管道传输丢内容,走文件中转稳妥)。

## 运行(含上游缺陷的绕过)

**上游缺陷(实测实锤)**:deploy/Dockerfile 里 `WORKDIR /app` 属主 root、jmqtt 用户(uid 999)无法创建 `/app/logs`,**logback 直接让启动失败**;仓库的 run.sh 没挂 logs 卷,原样执行必挂:

```
ERROR in ch.qos.logback...[FILE] - Failed to create parent directories for [/app/logs/jmqtt-broker.log]
```

绕过 = 挂载日志目录:

```bash
mkdir -p /data/jmqtt/logs && chown 999:999 /data/jmqtt/logs
docker run -d --name jmqtt-broker --restart=unless-stopped --net=host \
  -e TZ=Asia/Shanghai -e JMQTT_ID=node-1 \
  -e JMQTT_REDIS_ENABLED=true -e JMQTT_REDIS_HOST=127.0.0.1 \
  -e JMQTT_CLUSTER_ENABLED=true \
  -e JMQTT_KAFKA_ENABLED=true -e JMQTT_KAFKA_BOOTSTRAP_SERVERS=10.10.12.128:9092 \
  -v /data/jmqtt/logs:/app/logs \
  jmqtt-broker:lab
```

配套 Redis(单机形态,同机):

```bash
docker run -d --name jmqtt-redis --restart=always --net=host \
  -v /data/jmqtt/redis:/data \
  redis:8.0 redis-server --bind 127.0.0.1 --protected-mode yes --dir /data --appendonly yes
```

## 验证(实测输出)

```bash
# 启动要 90 秒上下(Spring + Kafka/Redis 装配),别急着判死:
docker logs jmqtt-broker | grep "Started JmqttBrokerApplication"
# Started JmqttBrokerApplication in 93.278 seconds
ss -tln | grep -E ":1883|:8083|:8922"        # 三端口就绪
curl -s localhost:8922/actuator/health        # {"status":"UP",...}
docker exec jmqtt-redis redis-cli keys "jmqtt*"   # jmqtt:admin:nodes 等
```

## 已知坑(实测)

| 坑 | 现象 | 解 |
| --- | --- | --- |
| **镜像 logs 目录缺陷** | logback Failed to create parent directories | `-v /data/jmqtt/logs:/app/logs`(+chown 999) |
| 启动 90 秒 | 误判挂了反复重启 | 等 Started 日志 |
| Kafka 缺 jmqtt-cluster topic | UNKNOWN_TOPIC_OR_PARTITION 刷屏 | 先建 topic(本文开头) |
| 本机 Redis 连不上 | broker 日志 Redis 冷却期循环 | --net=host 下 127.0.0.1 才同机;桥接网络要写宿主 IP |
