> - **覆盖对象**:S3 协议的对象存储(AWS S3、阿里云 OSS、腾讯云 COS、华为云 OBS 用法一致),以阿里云 OSS SDK 与 AWS S3 预签名 URL 为示例代码。
> - **技术栈**:Java 服务端(OSS/S3 SDK)、Elasticsearch 8 做元数据索引、Kibana 查询。
> - **文档性质**:方案与代码示例为主,第 6、7 篇的索引设计属规划稿,尚未在本文档环境跑过全链路。

## 这个目录在讲什么

对象存储是文件流的终点,坑集中在三处:文件流垫进服务端内存、AK/SK 落在服务端、权限与费用失控。第 1、2 篇解决前两个,第 3 到 5 篇解决权限与成本,第 6、7 篇把对象元数据搬进 ES 以便检索。

4 与 5 是替代关系,不是递进关系:4 用单桶加路径前缀区分公开与私有,5 用两个物理桶。前者运维简单、策略集中,后者隔离彻底、CORS 与 CDN 可分别配。先读 5 的「方案对比」一节再决定。
