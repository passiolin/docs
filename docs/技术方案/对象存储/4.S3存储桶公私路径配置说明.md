# S3 存储桶公共/私有路径配置方案

用户上传的文件，访问权限上有两种需求：
- **公共资源**：如商品图片、头像、Logo 等，需要被任意用户直接访问，通常走 CDN 加速。
- **私有资源**：如合同 PDF、用户隐私照片、内部文档等，必须经服务端授权（预签名 URL）才能访问。

本文档说明如何在同一个 S3 存储桶内，通过路径前缀隔离公共与私有资源，并结合 IAM、Bucket Policy、CORS 完成权限控制。

---

## 1. 总体方案选型

| 方案 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| **单 Bucket + 路径前缀** | 同一存储桶内，用 `public/` 和 `private/` 前缀区分 | 管理简单、成本低、统一域名/CDN | 权限策略需精细到路径级别 |
| **双 Bucket** | 一个 Public Bucket，一个 Private Bucket | 权限天然隔离，策略简单 | 需要维护两套域名、CDN、监控 |

**推荐方案：单 Bucket + 路径前缀**。原因：
- 减少运维复杂度（一套 Bucket、一套域名、一套监控）。
- 统一计费与生命周期管理。
- 通过 IAM Policy + Bucket Policy 的组合即可实现精细化权限控制。

---

## 2. 路径规划

在对象 Key 的第一级固定为 `public/` 或 `private/`，第二级按业务类型细分：

```
public/
  images/2026-05-09/{uuid}-avatar.png       # 用户头像
  images/2026-05-09/{uuid}-product.jpg      # 商品图
  videos/2026-05-09/{uuid}-preview.mp4      # 公开预览视频
private/
  documents/2026-05-09/{uuid}-contract.pdf  # 合同
  images/2026-05-09/{uuid}-idcard.jpg       # 身份证照片
  videos/2026-05-09/{uuid}-record.mp4       # 私有录像
```

### 2.1 服务端生成 objectKey 的规范

服务端必须控制路径生成，禁止客户端传入完整 `objectKey`：

```java
String objectKey = (isPublic ? "public/" : "private/")
        + fileType.getPathPrefix()
        + LocalDate.now() + "/"
        + UUID.randomUUID() + "-" + fileName;
```

## 3. Bucket Policy（桶级策略）

Bucket Policy 用于控制**匿名访问**权限：
- 允许任何人读取 `public/*` 路径下的对象。
- 拒绝任何人直接访问 `private/*` 路径（必须通过预签名 URL）。

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AllowPublicReadForPublicPath",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::your-bucket-name/public/*"
    },
    {
      "Sid": "DenyDirectAccessToPrivatePath",
      "Effect": "Deny",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::your-bucket-name/private/*",
      "Condition": {
        "StringEquals": {
          "aws:Referer": ""
        }
      }
    }
  ]
}
```

> **注意**：第二条 Deny 策略是可选的。因为 S3 默认拒绝所有匿名访问，只要第一条 `Allow` 只覆盖了 `public/*`，`private/*` 自然会被拒绝。但如果之前有过全桶开放的策略残留，建议显式 Deny。

## 4. IAM Policy（应用侧凭证策略）

为 Java 服务端应用创建独立的 IAM 用户，并授予最小权限：

### 4.1 业务端 IAM Policy（上传/下载）

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:PutObject",
        "s3:GetObject"
      ],
      "Resource": [
        "arn:aws:s3:::your-bucket-name/public/*",
        "arn:aws:s3:::your-bucket-name/private/*"
      ]
    }
  ]
}
```

### 4.2 管理后台 IAM Policy（含删除权限）

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:PutObject",
        "s3:GetObject",
        "s3:DeleteObject",
        "s3:ListBucket"
      ],
      "Resource": [
        "arn:aws:s3:::your-bucket-name",
        "arn:aws:s3:::your-bucket-name/public/*",
        "arn:aws:s3:::your-bucket-name/private/*"
      ]
    }
  ]
}
```

> **最小权限原则**：业务端与管理后台应使用不同的 IAM 用户或 Role，AK/SK 严格隔离。

## 5. CORS 配置

如果客户端是浏览器（Web 前端、小程序等），Bucket 必须配置 CORS，允许前端域名对 `public/` 和 `private/` 发起 `PUT` 和 `GET` 请求。

```xml
<CORSConfiguration>
  <CORSRule>
    <AllowedOrigin>https://your-domain.com</AllowedOrigin>
    <AllowedOrigin>https://admin.your-domain.com</AllowedOrigin>
    <AllowedMethod>PUT</AllowedMethod>
    <AllowedMethod>GET</AllowedMethod>
    <AllowedMethod>DELETE</AllowedMethod>
    <AllowedHeader>*</AllowedHeader>
    <MaxAgeSeconds>3000</MaxAgeSeconds>
  </CORSRule>
</CORSConfiguration>
```

> `AllowedOrigin` 不要使用 `*`，应严格限定生产与测试域名。

## 6. Java 代码层适配思路

以下为实现公共/私有路径隔离的代码设计建议（仅供参考，后续迭代实现）。

### 6.1 文件类型枚举增加可见性属性

```java
public enum FileTypeEnum {
    IMAGE("image/", 10 * 1024 * 1024L, 5, "images/", true),   // 默认公共
    DOCUMENT(..., false),   // 默认私有
    VIDEO(..., false),
    AUDIO(..., false),
    GENERIC(..., false);

    private final boolean defaultPublic; // 是否默认可公开访问
}
```

### 6.2 上传请求 DTO 增加可见性覆盖字段

```java
@Data
public class PresignedUploadRequestDTO {
    private String fileName;
    private String contentType;
    private String fileType;
    private Boolean isPublic; // 可选，不传则使用枚举默认值
}
```

### 6.3 服务端生成 objectKey 时区分 public/private

```java
FileTypeEnum fileType = FileTypeEnum.fromName(requestDTO.getFileType());
boolean isPublic = requestDTO.getIsPublic() != null
        ? requestDTO.getIsPublic()
        : fileType.isDefaultPublic();

String prefix = (isPublic ? "public/" : "private/") + fileType.getPathPrefix();
String objectKey = prefix + LocalDate.now() + "/" + UUID.randomUUID() + "-" + fileName;
```

### 6.4 下载时区分公共与私有

```java
public String getDownloadUrl(String objectKey, int expireMinutes) {
    if (objectKey.startsWith("public/")) {
        // 公共资源直接返回可访问 URL（无需预签名）
        return buildPublicUrl(objectKey);
    }
    // 私有资源生成预签名 URL
    return s3PresignedService.generateDownloadUrl(objectKey, expireMinutes);
}
```

### 6.5 公共 URL 构建方式

```java
public String buildPublicUrl(String objectKey) {
    if (cdnDomain != null && !cdnDomain.isBlank()) {
        return cdnDomain + "/" + objectKey;  // CDN 加速地址
    }
    if (endpoint != null && !endpoint.isBlank()) {
        return endpoint + "/" + bucket + "/" + objectKey;  // 自定义端点
    }
    return "https://" + bucket + ".s3." + region + ".amazonaws.com/" + objectKey;
}
```

## 8. 安全与最佳实践

| 实践项 | 说明 |
|--------|------|
| **服务端控制路径** | `public/` 和 `private/` 前缀必须由服务端生成，禁止客户端传入完整路径，防止路径遍历或伪造权限。 |
| **默认最小权限** | 新文件类型默认标记为 `private`，需要显式审批才能开放为 `public`。 |
| **CDN 回源鉴权** | 如果公共文件使用 CDN 加速，建议配置 CDN 的回源鉴权（如 AWS CloudFront 的 Origin Access Identity），避免源站被直接访问。 |
| **生命周期管理** | 对 `private/temp/` 等临时路径配置生命周期规则，自动删除过期文件，降低存储成本。 |
| **操作审计** | 开启 S3 Server Access Logging 或 Event Notification，记录所有 `private/*` 的下载和删除行为，便于安全审计。 |
| **Block Public Access** | Bucket 级别的 "Block Public Access" 保持启用，通过 Bucket Policy 精细控制，而非全局开放。 |

## 9. 流程总结

```
上传流程：
  客户端 -> 服务端申请上传 URL（携带 fileType + isPublic）
  服务端 -> 根据类型和可见性生成 objectKey（public/images/... 或 private/docs/...）
  服务端 -> 生成预签名 PUT URL 返回给客户端
  客户端 -> 直传 S3（数据不经过服务端）

下载流程（公共）：
  客户端 -> 直接访问 CDN/源站 URL（如 https://cdn.example.com/public/images/...）

下载流程（私有）：
  客户端 -> 向服务端申请下载 URL（携带 objectKey）
  服务端 -> 识别到 private/ 前缀，生成预签名 GET URL
  客户端 -> 使用预签名 URL 下载（有时效限制）
```
