# Java 集成 S3 预签名 URL 实现文件上传与下载

使用预签名 URL（Presigned URL）是服务端与对象存储交互的最佳实践之一：服务端仅负责生成带权限和时效的 URL，客户端通过该 URL 直接对 S3 发起上传或下载请求，数据流不经过服务端，从根本上避免大文件导致的内存溢出（OOM）和带宽瓶颈。

---

## 1. 运维侧需提供的配置

在开发接入前，需要运维/云平台管理员完成以下基础配置。

### 1.1 IAM 用户与访问密钥

为应用创建独立的 IAM 用户，并生成 `Access Key ID` 和 `Secret Access Key`。

- **最小权限原则**：不同场景应使用不同的 IAM 策略，严禁直接授予 `s3:*`。
  - **业务端（上传/下载）**：仅需 `s3:PutObject` + `s3:GetObject`。
  - **管理后台（删除）**：额外需要 `s3:DeleteObject`。建议为管理后台单独分配 IAM 用户或 Role，与业务端隔离。

**业务端 IAM Policy 示例**：

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:PutObject",
        "s3:GetObject"
      ],
      "Resource": "arn:aws:s3:::your-bucket-name/uploads/*"
    }
  ]
}
```

**管理后台 IAM Policy 示例**：

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:PutObject",
        "s3:GetObject",
        "s3:DeleteObject"
      ],
      "Resource": "arn:aws:s3:::your-bucket-name/uploads/*"
    }
  ]
}
```

> **说明**：`Resource` 建议限制到具体路径前缀（如 `uploads/*`），防止预签名 URL 被用于访问其他对象。生产环境建议业务端与管理后台使用不同的 AK/SK，实现权限隔离。

### 1.2 Bucket CORS 配置

如果客户端是浏览器（Web 前端、小程序等），必须在 Bucket 上配置 CORS，允许前端域名的 `PUT` 和 `GET` 请求。

```xml
<CORSConfiguration>
  <CORSRule>
    <AllowedOrigin>https://your-domain.com</AllowedOrigin>
    <AllowedMethod>PUT</AllowedMethod>
    <AllowedMethod>GET</AllowedMethod>
    <AllowedMethod>DELETE</AllowedMethod>
    <AllowedHeader>*</AllowedHeader>
    <MaxAgeSeconds>3000</MaxAgeSeconds>
  </CORSRule>
</CORSConfiguration>
```

> **说明**：`AllowedOrigin` 不要使用 `*`，应严格限定生产与测试域名。

### 1.3 Bucket 公网访问策略（可选）

预签名 URL 本身已包含鉴权信息，Bucket 及对象 **无需** 设置为 Public。请确保 Bucket 的 Block Public Access 处于启用状态，防止对象被匿名访问。

### 1.4 服务端所需环境变量

运维将以下配置注入到 Java 服务的运行环境中（如 Kubernetes Secret、Nacos、Apollo 等）：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| `s3.access-key` | IAM 用户 Access Key ID | `AKIA...` |
| `s3.secret-key` | IAM 用户 Secret Access Key | `wJalrXUtnFEMI...` |
| `s3.region` | Bucket 所在区域 | `ap-southeast-1` |
| `s3.bucket` | 默认 Bucket 名称 | `my-app-bucket` |
| `s3.endpoint` | 自定义 S3 兼容端点（可选） | `https://obs.cn-north-4.myhuaweicloud.com` |

> 若使用 AWS S3 官方服务，`endpoint` 通常留空，由 SDK 根据 `region` 自动解析。

## 2. Java 服务端集成

### 2.1 Maven 依赖

```xml
<dependency>
    <groupId>software.amazon.awssdk</groupId>
    <artifactId>s3</artifactId>
    <version>2.25.0</version>
</dependency>
```

> 使用 AWS SDK for Java v2，v1 的 `AmazonS3` 已处于维护模式。

### 2.2 配置属性类

使用 `@ConfigurationProperties` 将 S3 相关配置收拢到独立的 POJO 中，避免在业务代码中到处写 `@Value`。

```java
import lombok.Data;
import org.springframework.boot.context.properties.ConfigurationProperties;

@Data
@ConfigurationProperties(prefix = "s3")
public class S3Properties {

    /** IAM Access Key ID */
    private String accessKey;

    /** IAM Secret Access Key */
    private String secretKey;

    /** Bucket 所在区域，默认新加坡 */
    private String region = "ap-southeast-1";

    /** 默认 Bucket 名称 */
    private String bucket;

    /** 自定义 S3 兼容端点，如 MinIO、华为云 OBS。使用 AWS 官方 S3 时可留空 */
    private String endpoint;
}
```

> 需在启动类或配置类上添加 `@EnableConfigurationProperties(S3Properties.class)` 开启绑定。

### 2.3 S3 客户端配置

```java
import org.springframework.boot.context.properties.EnableConfigurationProperties;
import software.amazon.awssdk.auth.credentials.AwsBasicCredentials;
import software.amazon.awssdk.auth.credentials.StaticCredentialsProvider;
import software.amazon.awssdk.regions.Region;
import software.amazon.awssdk.services.s3.S3Configuration;
import software.amazon.awssdk.services.s3.presigner.S3Presigner;
import java.net.URI;

@Configuration
@EnableConfigurationProperties(S3Properties.class)
public class S3Config {

    private final S3Properties s3Properties;

    public S3Config(S3Properties s3Properties) {
        this.s3Properties = s3Properties;
    }

    @Bean
    public S3Client s3Client() {
        AwsBasicCredentials credentials = AwsBasicCredentials.create(
                s3Properties.getAccessKey(),
                s3Properties.getSecretKey()
        );

        S3Client.Builder builder = S3Client.builder()
                .credentialsProvider(StaticCredentialsProvider.create(credentials))
                .region(Region.of(s3Properties.getRegion()));

        if (StringUtils.hasText(s3Properties.getEndpoint())) {
            builder.endpointOverride(URI.create(s3Properties.getEndpoint()))
                   .serviceConfiguration(S3Configuration.builder()
                           .pathStyleAccessEnabled(true)
                           .build());
        }

        return builder.build();
    }

    @Bean
    public S3Presigner s3Presigner() {
        AwsBasicCredentials credentials = AwsBasicCredentials.create(
                s3Properties.getAccessKey(),
                s3Properties.getSecretKey()
        );

        S3Presigner.Builder builder = S3Presigner.builder()
                .credentialsProvider(StaticCredentialsProvider.create(credentials))
                .region(Region.of(s3Properties.getRegion()));

        // 若使用 MinIO、华为云 OBS、阿里云 OSS（S3兼容）等，需要显式配置 endpoint
        if (StringUtils.hasText(s3Properties.getEndpoint())) {
            builder.endpointOverride(URI.create(s3Properties.getEndpoint()))
                   .serviceConfiguration(S3Configuration.builder()
                           .pathStyleAccessEnabled(true) // 非 AWS 厂商通常需要开启 path-style
                           .build());
        }

        return builder.build();
    }
}
```

### 2.3 生成预签名上传 URL

```java
import software.amazon.awssdk.services.s3.S3Client;
import software.amazon.awssdk.services.s3.model.PutObjectRequest;
import software.amazon.awssdk.services.s3.presigner.model.PutObjectPresignRequest;
import software.amazon.awssdk.services.s3.presigner.model.PresignedPutObjectRequest;
import java.time.Duration;

@Service
public class S3PresignedService {

    private final S3Presigner s3Presigner;
    private final S3Client s3Client;
    private final S3Properties s3Properties;

    public S3PresignedService(S3Presigner s3Presigner, S3Client s3Client, S3Properties s3Properties) {
        this.s3Presigner = s3Presigner;
        this.s3Client = s3Client;
        this.s3Properties = s3Properties;
    }

    /**
     * 生成预签名上传 URL
     *
     * @param objectKey  对象在 S3 中的路径，如 "uploads/2024/report.pdf"
     * @param expireMinutes URL 有效期（分钟）
     * @param contentType  限制客户端上传的 Content-Type，如 "application/pdf"
     * @param maxContentLength 允许的最大文件大小（字节），可选
     */
    public String generateUploadUrl(String objectKey, int expireMinutes,
                                    String contentType, Long maxContentLength) {

        PutObjectRequest.Builder putBuilder = PutObjectRequest.builder()
                .bucket(s3Properties.getBucket())
                .key(objectKey)
                .contentType(contentType);

        if (maxContentLength != null) {
            putBuilder.contentLength(maxContentLength);
        }

        PutObjectPresignRequest presignRequest = PutObjectPresignRequest.builder()
                .signatureDuration(Duration.ofMinutes(expireMinutes))
                .putObjectRequest(putBuilder.build())
                .build();

        PresignedPutObjectRequest presignedRequest = s3Presigner.presignPutObject(presignRequest);
        return presignedRequest.url().toString();
    }
}
```

**Controller 示例**：

```java
@RestController
@RequestMapping("/api/files")
public class FileController {

    @Autowired
    private S3PresignedService s3PresignedService;

    @GetMapping("/upload-url")
    public Result<Map<String, String>> getUploadUrl(
            @RequestParam String fileName,
            @RequestParam String contentType) {

        // 服务端控制文件路径和命名，防止客户端伪造
        String objectKey = "uploads/" + LocalDate.now() + "/" + UUID.randomUUID() + "-" + fileName;

        String url = s3PresignedService.generateUploadUrl(objectKey, 5, contentType, 10 * 1024 * 1024L);

        return Result.ok(Map.of(
            "presignedUrl", url,
            "objectKey", objectKey,
            "accessUrl", "/api/files/download-url?key=" + objectKey
        ));
    }
}
```

### 2.4 生成预签名下载 URL

```java
import software.amazon.awssdk.services.s3.model.GetObjectRequest;
import software.amazon.awssdk.services.s3.presigner.model.GetObjectPresignRequest;
import software.amazon.awssdk.services.s3.presigner.model.PresignedGetObjectRequest;

public String generateDownloadUrl(String objectKey, int expireMinutes) {
    GetObjectRequest getObjectRequest = GetObjectRequest.builder()
            .bucket(s3Properties.getBucket())
            .key(objectKey)
            .build();

    GetObjectPresignRequest getPresignRequest = GetObjectPresignRequest.builder()
            .signatureDuration(Duration.ofMinutes(expireMinutes))
            .getObjectRequest(getObjectRequest)
            .build();

    PresignedGetObjectRequest presignedGetObjectRequest =
            s3Presigner.presignGetObject(getPresignRequest);

    return presignedGetObjectRequest.url().toString();
}
```

> 下载 URL 可以设置更长的有效期（如 30 分钟），或结合业务动态调整。

### 2.5 删除对象

管理后台通常需要清理过期或违规文件。删除操作没有文件流量压力，**推荐由服务端直接调用 SDK 删除**，无需预签名。

```java
import software.amazon.awssdk.services.s3.model.DeleteObjectRequest;

/**
 * 服务端直接删除对象（管理后台推荐）
 */
public void deleteObject(String objectKey) {
    DeleteObjectRequest deleteRequest = DeleteObjectRequest.builder()
            .bucket(s3Properties.getBucket())
            .key(objectKey)
            .build();

    s3Client.deleteObject(deleteRequest);
}
```

**管理后台 Controller 示例**：

```java
@RestController
@RequestMapping("/admin/oss")
public class AdminOssController {

    private final S3PresignedService s3PresignedService;

    public AdminOssController(S3PresignedService s3PresignedService) {
        this.s3PresignedService = s3PresignedService;
    }

    @DeleteMapping("/objects")
    public Result<Void> deleteObject(@RequestParam String objectKey) {
        // 建议在此处增加操作审计日志、权限校验（如仅管理员可操作）
        s3PresignedService.deleteObject(objectKey);
        return Result.ok();
    }
}
```

> **注意**：删除权限应严格管控，禁止向业务端用户开放。建议管理后台使用独立的 IAM 用户或 STS Role，与业务端 AK/SK 隔离。

## 3. 客户端使用方式

### 3.1 浏览器前端上传（Axios 示例）

```javascript
// 1. 从 Java 服务端获取预签名 URL
const res = await axios.get('/api/files/upload-url', {
  params: { fileName: 'avatar.png', contentType: 'image/png' }
});
const { presignedUrl, objectKey } = res.data;

// 2. 使用 PUT 方法直接上传到 S3
await axios.put(presignedUrl, file, {
  headers: {
    'Content-Type': 'image/png'
  }
});

// 3. 如需下载，再次请求服务端生成下载 URL
const downloadRes = await axios.get('/api/files/download-url', {
  params: { key: objectKey }
});
window.open(downloadRes.data.presignedUrl, '_blank');
```

> **注意**：上传时必须携带与生成 URL 时一致的 `Content-Type` Header，否则 S3 会返回 `403 SignatureDoesNotMatch`。

### 3.2 移动端 / 后端服务使用

移动端或其他后端服务流程与前端一致：先请求业务服务端获取预签名 URL，再使用该 URL 直传 S3。

## 4. 安全与最佳实践

| 实践项 | 说明 |
|--------|------|
| **服务端控制路径** | 文件名、目录结构必须由服务端生成，禁止客户端传入完整 `objectKey`，防止覆盖其他文件或遍历路径。 |
| **限制 Content-Type** | 生成上传 URL 时限定 `Content-Type`，避免客户端上传可执行文件（如 `.html`、`.js`）引发 XSS。 |
| **限制 Content-Length** | 通过 `contentLength` 限制单文件大小，防止恶意上传超大文件耗尽存储配额。 |
| **短时效** | 上传 URL 建议有效期不超过 5 分钟，下载 URL 不超过 30 分钟。 |
| **服务端限流** | 对 `获取预签名 URL` 的接口做限流（如基于 Sentinel、Redis 计数器），防止攻击者批量刷 URL。 |
| **Bucket 私有** | 关闭 Bucket 的 Public Access，所有对象访问必须依赖预签名 URL 或 IAM Role。 |
| **使用临时凭证（可选进阶）** | 在高安全场景下，服务端使用 STS 临时凭证生成预签名 URL，进一步降低 AK/SK 泄露风险。 |

## 5. 总结

| 对比项 | 传统服务端中转 | 预签名 URL 直传 |
|--------|---------------|----------------|
| 服务端内存压力 | 高（文件流经 JVM 堆内存） | 低（服务端只生成 URL） |
| 带宽成本 | 双份（客户端→服务端→S3） | 单份（客户端↔S3） |
| 并发能力 | 受限于服务端带宽和内存 | 取决于 S3 厂商上限 |
| 安全性 | 需要服务端托管 AK/SK，且文件落地服务端 | 服务端不接触文件数据，URL 有时效和路径绑定 |
