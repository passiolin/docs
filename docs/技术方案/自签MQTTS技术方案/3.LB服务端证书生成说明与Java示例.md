# LB 服务端证书生成说明与 Java 示例

## 一、LB 服务端证书所需信息

LB 服务端证书用于**负载均衡器（Load Balancer）的 TLS 终结**，在 MQTTS 握手时向设备端提供服务端身份凭证。该证书由**中间 CA 私钥**签名，属于终端实体证书。

### 1. Subject 主体信息（Distinguished Name）

| 字段 | OID / 缩写 | 说明 | 示例 |
|:---|:---|:---|:---|
| **Common Name** | `CN` | 服务端域名，必须与设备端连接地址一致 | `mqtt.ipuff.online` |
| **Organization** | `O` | 组织/公司名 | `ipuff.online Inc.` |
| **Organizational Unit** | `OU` | 部门/单位（可选） | `Platform` |
| **Country** | `C` | 国家代码（ISO 3166-1 alpha-2） | `US` |
| **State or Province** | `ST` | 省/州（可选） | `California` |
| **Locality** | `L` | 城市（可选） | `San Francisco` |

> **注意**：`CN` 必须与设备端 MQTTS 连接时使用的域名完全一致，否则会导致 TLS 握手失败。若需支持多域名，应在 **SAN（Subject Alternative Name）** 扩展中添加。

### 2. Subject Alternative Name（SAN）扩展

| 类型 | 值 | 说明 |
|:---|:---|:---|
| **DNS** | `mqtt.ipuff.online` | 主域名（与 CN 一致） |
| **DNS** | `*.ipuff.online` | 通配符域名（如需要支持子域名） |
| **IP** | `192.168.1.100` | 若设备通过 IP 直连 LB，需添加 IP SAN |

> **建议**：现代 TLS 客户端（如 OpenSSL 1.1.1+）会优先校验 SAN 而非 CN，因此即使单域名也建议配置 SAN。

### 3. 密钥算法与长度

| 项目 | 推荐值 | 说明 |
|:---|:---|:---|
| **算法** | RSA | 兼容性最佳，推荐 |
| **密钥长度** | 2048 位 | 满足 NIST / PCI DSS 等主流合规要求 |
| **签名算法** | SHA-256 | `SHA256withRSA` 为当前主流 |

### 4. 标准扩展（X509v3 Extensions）

| 扩展名 | 必需 | 值 / 说明 |
|:---|:---|:---|
| **BasicConstraints** | 是 | `CA:FALSE`（明确标识为终端实体证书） |
| **KeyUsage** | 是 | `DigitalSignature`（签名）、`KeyEncipherment`（密钥加密） |
| **ExtendedKeyUsage** | 是 | `serverAuth`（服务端身份认证） |
| **SubjectKeyIdentifier** | 是 | 主体密钥标识符 |
| **AuthorityKeyIdentifier** | 是 | 指向签发者（中间 CA）的公钥标识 |
| **SubjectAlternativeName** | 是 | 域名 / IP 列表，现代客户端优先校验 |

### 5. 有效期

- LB 服务端证书有效期通常设为 **1 ~ 3 年**
- 短于中间 CA，便于定期轮转，降低证书泄露风险

### 6. 序列号

- 必须为唯一的正整数
- 建议采用随机大整数，避免与已有证书冲突

## 二、Java 生成 LB 服务端证书示例

以下示例使用 **BouncyCastle** 库，以**中间 CA 私钥**签名生成 LB 服务端证书。运行前需先准备好中间 CA 证书及私钥文件（PEM 格式）。

### Maven 依赖

```xml
<dependency>
    <groupId>org.bouncycastle</groupId>
    <artifactId>bcprov-jdk18on</artifactId>
    <version>1.78</version>
</dependency>
```

### 完整代码

```java
import org.bouncycastle.asn1.ASN1Encodable;
import org.bouncycastle.asn1.DERSequence;
import org.bouncycastle.asn1.x500.X500Name;
import org.bouncycastle.asn1.x509.*;
import org.bouncycastle.cert.X509v3CertificateBuilder;
import org.bouncycastle.cert.jcajce.JcaX509CertificateConverter;
import org.bouncycastle.cert.jcajce.JcaX509ExtensionUtils;
import org.bouncycastle.openssl.PEMKeyPair;
import org.bouncycastle.openssl.PEMParser;
import org.bouncycastle.openssl.jcajce.JcaPEMKeyConverter;
import org.bouncycastle.operator.ContentSigner;
import org.bouncycastle.operator.jcajce.JcaContentSignerBuilder;
import org.bouncycastle.util.io.pem.PemObject;
import org.bouncycastle.util.io.pem.PemWriter;

import java.io.StringReader;
import java.io.StringWriter;
import java.math.BigInteger;
import java.security.*;
import java.security.cert.X509Certificate;
import java.util.Date;

public class LbServerCertGenerator {

    /**
     * 中间 CA 证书 PEM 字符串（用于提取 Issuer 和 AKI）
     */
    private static final String INTERMEDIATE_CA_CERT_PEM = """
            -----BEGIN CERTIFICATE-----
            MIIDXTCCAkWgAwIBAgIQC2Z...（请替换为实际中间 CA 证书内容）
            -----END CERTIFICATE-----
            """;

    /**
     * 中间 CA 私钥 PEM 字符串（用于签名 LB 服务端证书）
     */
    private static final String INTERMEDIATE_CA_KEY_PEM = """
            -----BEGIN PRIVATE KEY-----
            MIIEvQIBADANBgkqhkiG9w0B...（请替换为实际中间 CA 私钥内容）
            -----END PRIVATE KEY-----
            """;

    public static void main(String[] args) throws Exception {
        // 1. 注册 BouncyCastle 安全提供者
        Security.addProvider(new org.bouncycastle.jce.provider.BouncyCastleProvider());

        // 2. 加载中间 CA 证书和私钥
        X509Certificate intermediateCert = loadCertificate(INTERMEDIATE_CA_CERT_PEM);
        PrivateKey intermediatePrivateKey = loadPrivateKey(INTERMEDIATE_CA_KEY_PEM);

        // 3. 生成 LB 服务端 RSA 2048 密钥对
        KeyPairGenerator keyGen = KeyPairGenerator.getInstance("RSA", "BC");
        keyGen.initialize(2048, new SecureRandom());
        KeyPair keyPair = keyGen.generateKeyPair();

        // 4. 构建 Issuer（中间 CA Subject）和 Subject（LB 证书 Subject）
        X500Name issuer = new X500Name(intermediateCert.getSubjectX500Principal().getName());
        X500Name subject = new X500Name(
                "C=US, ST=California, L=San Francisco, O=ipuff.online Inc., OU=Platform, CN=mqtt.ipuff.online"
        );

        // 5. 有效期：3 年
        long now = System.currentTimeMillis();
        Date notBefore = new Date(now);
        Date notAfter = new Date(now + 3L * 365 * 24 * 60 * 60 * 1000);

        // 6. 随机序列号
        BigInteger serialNumber = new BigInteger(160, new SecureRandom());

        // 7. 构造证书 Builder
        SubjectPublicKeyInfo publicKeyInfo = SubjectPublicKeyInfo.getInstance(
                keyPair.getPublic().getEncoded()
        );
        X509v3CertificateBuilder certBuilder = new X509v3CertificateBuilder(
                issuer,           // issuer = 中间 CA Subject
                serialNumber,
                notBefore,
                notAfter,
                subject,          // subject = LB 证书 Subject
                publicKeyInfo
        );

        // 8. 添加扩展
        JcaX509ExtensionUtils extUtils = new JcaX509ExtensionUtils();

        // SubjectKeyIdentifier
        certBuilder.addExtension(
                Extension.subjectKeyIdentifier,
                false,
                extUtils.createSubjectKeyIdentifier(keyPair.getPublic())
        );

        // AuthorityKeyIdentifier（指向中间 CA 的公钥）
        certBuilder.addExtension(
                Extension.authorityKeyIdentifier,
                false,
                extUtils.createAuthorityKeyIdentifier(intermediateCert)
        );

        // BasicConstraints: CA = false
        certBuilder.addExtension(
                Extension.basicConstraints,
                true,
                new BasicConstraints(false)
        );

        // KeyUsage: DigitalSignature + KeyEncipherment
        certBuilder.addExtension(
                Extension.keyUsage,
                true,
                new KeyUsage(KeyUsage.digitalSignature | KeyUsage.keyEncipherment)
        );

        // ExtendedKeyUsage: serverAuth
        certBuilder.addExtension(
                Extension.extendedKeyUsage,
                false,
                new ExtendedKeyUsage(new KeyPurposeId[]{ KeyPurposeId.id_kp_serverAuth })
        );

        // SubjectAlternativeName: DNS + IP（如有需要）
        GeneralName[] sanNames = new GeneralName[]{
                new GeneralName(GeneralName.dNSName, "mqtt.ipuff.online"),
                new GeneralName(GeneralName.dNSName, "*.ipuff.online"),
                // new GeneralName(GeneralName.iPAddress, "192.168.1.100") // 如需 IP 直连，取消注释
        };
        certBuilder.addExtension(
                Extension.subjectAlternativeName,
                false,
                new GeneralNames(sanNames)
        );

        // 9. 使用中间 CA 私钥签名
        ContentSigner signer = new JcaContentSignerBuilder("SHA256withRSA")
                .setProvider("BC")
                .build(intermediatePrivateKey);

        X509Certificate cert = new JcaX509CertificateConverter()
                .setProvider("BC")
                .getCertificate(certBuilder.build(signer));

        // 10. 输出 PEM
        System.out.println("========== LB 服务端证书 (Server Certificate) ==========");
        System.out.println(toPem("CERTIFICATE", cert.getEncoded()));

        System.out.println("========== LB 服务端私钥 (Private Key) ==========");
        System.out.println(toPem("PRIVATE KEY", keyPair.getPrivate().getEncoded()));

        System.out.println("========== 证书链验证 ==========");
        cert.verify(intermediateCert.getPublicKey());
        System.out.println("证书链验证通过：LB 服务端证书已由中间 CA 正确签名。");
    }

    private static X509Certificate loadCertificate(String pem) throws Exception {
        try (PEMParser parser = new PEMParser(new StringReader(pem))) {
            Object obj = parser.readObject();
            return new JcaX509CertificateConverter()
                    .setProvider("BC")
                    .getCertificate((org.bouncycastle.cert.X509CertificateHolder) obj);
        }
    }

    private static PrivateKey loadPrivateKey(String pem) throws Exception {
        try (PEMParser parser = new PEMParser(new StringReader(pem))) {
            Object obj = parser.readObject();
            if (obj instanceof PEMKeyPair) {
                return new JcaPEMKeyConverter()
                        .setProvider("BC")
                        .getKeyPair((PEMKeyPair) obj)
                        .getPrivate();
            } else if (obj instanceof PrivateKey) {
                return (PrivateKey) obj;
            } else {
                throw new IllegalArgumentException("不支持的私钥格式: " + obj.getClass());
            }
        }
    }

    private static String toPem(String type, byte[] data) throws Exception {
        StringWriter sw = new StringWriter();
        try (PemWriter pw = new PemWriter(sw)) {
            pw.writeObject(new PemObject(type, data));
        }
        return sw.toString();
    }
}
```

### 运行结果说明

程序输出两段 PEM：

1. **`CERTIFICATE`** —— LB 服务端证书公钥，需配置到负载均衡器（LB）的 TLS 配置中
2. **`PRIVATE KEY`** —— LB 服务端私钥，**与证书一同配置到 LB**，用于 TLS 握手时的密钥交换

### 证书链配置

LB 在 TLS 握手时需向设备端发送**完整证书链**：

```
LB 服务端证书
+ 中间 CA 证书
（设备端已预置根证书，用于验证中间 CA）
```

配置方式（以 Nginx 为例）：

```nginx
ssl_certificate     /etc/nginx/ssl/ipuff.online-chain.pem;  # 服务端证书 + 中间 CA 合并
ssl_certificate_key /etc/nginx/ssl/ipuff.online.key;        # 服务端私钥
```

### 安全建议

- LB 服务端私钥应限制文件权限（如 `chmod 600`），避免非必要进程读取
- 定期轮转 LB 服务端证书（如每年续期），降低密钥泄露影响
- 私钥建议加密存储，LB 启动时通过环境变量或密钥管理服务（KMS）解密加载
- 若 LB 支持，优先启用 **OCSP Stapling**，提升证书状态校验效率
