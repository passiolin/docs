# 根证书（Root CA）生成说明与 Java 示例

## 一、根证书所需信息

根证书是整个 PKI 体系的信任锚点，由它自签名，并用于签发中间 CA 或设备证书。以下信息在生成时必须明确：

### 1. Subject 主体信息（Distinguished Name）

| 字段 | OID / 缩写 | 说明 | 示例 |
|:---|:---|:---|:---|
| **Common Name** | `CN` | 证书名称，通常固定为 `Root CA` | `ipuff.online Root CA` |
| **Organization** | `O` | 组织/公司名 | `ipuff.online Inc.` |
| **Organizational Unit** | `OU` | 部门/单位（可选） | `Security` |
| **Country** | `C` | 国家代码（ISO 3166-1 alpha-2） | `US` |
| **State or Province** | `ST` | 省/州（可选） | `California` |
| **Locality** | `L` | 城市（可选） | `San Francisco` |
| **Email Address** | 无标准 OID | 联系邮箱（可选，旧标准中常用） | `security@example.com` |

> **建议**：根证书的 `Subject` 信息一旦确定，后续不应变更，否则会导致整个证书链失效。

### 2. 密钥算法与长度

| 项目 | 推荐值 | 说明 |
|:---|:---|:---|
| **算法** | RSA | 兼容性最佳，推荐 |
| **密钥长度** | 2048 位 | 满足 NIST / PCI DSS 等主流合规要求；根证书因有效期长达 30 年，若安全等级要求极高可评估 3072 或 4096 |
| **签名算法** | SHA-256 / SHA-384 | `SHA256withRSA` 为当前主流 |

### 3. 标准扩展（X509v3 Extensions）

| 扩展名 | 必需 | 值 / 说明 |
|:---|:---|:---|
| **BasicConstraints** | 是 | `CA:TRUE`，可设置 `pathlen` 限制（如 `pathlen:1` 表示只能签发一层下级 CA） |
| **KeyUsage** | 是 | `Certificate Sign`（签发证书）、`CRL Sign`（签发 CRL） |
| **SubjectKeyIdentifier** | 是 | 主体密钥标识符，用于构建证书链时快速匹配 |
| **AuthorityKeyIdentifier** | 是 | 权威密钥标识符，自签名根证书中通常与 `SubjectKeyIdentifier` 相同 |
| **CRLDistributionPoint** | 否 | CRL 吊销列表下载地址（如有部署 CRL 服务则建议配置） |

### 4. 有效期

- 根证书有效期通常设为 **10 ~ 30 年**
- 由于更新根证书成本极高（需重新预置到所有设备），有效期应足够长

### 5. 序列号

- 必须为唯一的正整数
- 建议采用随机大整数，避免与已有证书冲突

## 二、Java 生成根证书示例

以下示例使用 **BouncyCastle** 库生成 PEM 格式的根证书及私钥。

### Maven 依赖

```xml
<dependency>
    <groupId>org.bouncycastle</groupId>
    <artifactId>bcprov-jdk18on</artifactId>
    <version>1.78</version>
</dependency>
```

### 完整代码

```java
import org.bouncycastle.asn1.x500.X500Name;
import org.bouncycastle.asn1.x509.BasicConstraints;
import org.bouncycastle.asn1.x509.Extension;
import org.bouncycastle.asn1.x509.KeyUsage;
import org.bouncycastle.asn1.x509.SubjectPublicKeyInfo;
import org.bouncycastle.cert.X509v3CertificateBuilder;
import org.bouncycastle.cert.jcajce.JcaX509CertificateConverter;
import org.bouncycastle.cert.jcajce.JcaX509ExtensionUtils;
import org.bouncycastle.operator.ContentSigner;
import org.bouncycastle.operator.jcajce.JcaContentSignerBuilder;
import org.bouncycastle.util.io.pem.PemObject;
import org.bouncycastle.util.io.pem.PemWriter;

import java.io.StringWriter;
import java.math.BigInteger;
import java.security.*;
import java.security.cert.X509Certificate;
import java.util.Date;

public class RootCaGenerator {

    public static void main(String[] args) throws Exception {
        // 1. 注册 BouncyCastle 安全提供者
        Security.addProvider(new org.bouncycastle.jce.provider.BouncyCastleProvider());

        // 2. 生成 RSA 4096 密钥对
        KeyPairGenerator keyGen = KeyPairGenerator.getInstance("RSA", "BC");
        keyGen.initialize(4096, new SecureRandom());
        KeyPair keyPair = keyGen.generateKeyPair();

        // 3. 构建 Subject
        X500Name subject = new X500Name(
                "C=US, ST=California, L=San Francisco, O=ipuff.online Inc., OU=Security, CN=ipuff.online Root CA"
        );

        // 4. 有效期：30 年
        long now = System.currentTimeMillis();
        Date notBefore = new Date(now);
        Date notAfter = new Date(now + 30L * 365 * 24 * 60 * 60 * 1000);

        // 5. 随机序列号
        BigInteger serialNumber = new BigInteger(160, new SecureRandom());

        // 6. 构造证书 Builder
        SubjectPublicKeyInfo publicKeyInfo = SubjectPublicKeyInfo.getInstance(
                keyPair.getPublic().getEncoded()
        );
        X509v3CertificateBuilder certBuilder = new X509v3CertificateBuilder(
                subject,          // issuer = subject（自签名）
                serialNumber,
                notBefore,
                notAfter,
                subject,          // subject
                publicKeyInfo
        );

        // 7. 添加扩展
        JcaX509ExtensionUtils extUtils = new JcaX509ExtensionUtils();

        // SubjectKeyIdentifier
        certBuilder.addExtension(
                Extension.subjectKeyIdentifier,
                false,
                extUtils.createSubjectKeyIdentifier(keyPair.getPublic())
        );

        // AuthorityKeyIdentifier（自签名，指向自身公钥）
        certBuilder.addExtension(
                Extension.authorityKeyIdentifier,
                false,
                extUtils.createAuthorityKeyIdentifier(keyPair.getPublic())
        );

        // BasicConstraints: CA = true, pathlen = 1（限制只能签发一级中间 CA）
        certBuilder.addExtension(
                Extension.basicConstraints,
                true,
                new BasicConstraints(1)
        );

        // KeyUsage: Certificate Sign + CRL Sign
        certBuilder.addExtension(
                Extension.keyUsage,
                true,
                new KeyUsage(KeyUsage.keyCertSign | KeyUsage.cRLSign)
        );

        // 8. 使用私钥签名
        ContentSigner signer = new JcaContentSignerBuilder("SHA256withRSA")
                .setProvider("BC")
                .build(keyPair.getPrivate());

        X509Certificate cert = new JcaX509CertificateConverter()
                .setProvider("BC")
                .getCertificate(certBuilder.build(signer));

        // 9. 输出 PEM
        System.out.println("========== 根证书 (Root CA) ==========");
        System.out.println(toPem("CERTIFICATE", cert.getEncoded()));

        System.out.println("========== 私钥 (Private Key) ==========");
        System.out.println(toPem("PRIVATE KEY", keyPair.getPrivate().getEncoded()));
    }

    private static String toPem(String type, byte[] data) throws Exception {
        StringWriter sw = new StringWriter();
        try (PemWriter pw = new PemWriter(sw)) {
            pw.writeObject(new PemObject(type, data));
        }
        return sw.toString();
    }
}
```

### 运行结果说明

程序输出两段 PEM：

1. **`CERTIFICATE`** —— 根证书公钥，需预置到所有设备和 LB 作为信任锚点
2. **`PRIVATE KEY`** —— 根证书私钥，**必须离线加密保存**，严禁部署到线上服务器

### 安全建议

- 根证书私钥应在**离线安全环境**（如 HSM、加密机或物理隔离的密钥管理服务器）中生成和存储
- 日常签发证书应使用**中间 CA**，避免直接使用根证书私钥
- 私钥文件建议使用密码加密（如 PKCS#8 格式），可使用 `openssl pkcs8 -topk8` 转换
