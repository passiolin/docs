# 自签 MQTTS 技术方案(自签MQTTS技术方案)

> - **覆盖范围**:自建私有 CA 为 IoT 设备签发证书,设备以 mTLS 接入 MQTTS,**TLS 在 LB 终结**,Broker 不处理 SSL。
> - **PKI 形态**:根 CA → 中间 CA → 设备证书/服务端证书两级签发,CA 私钥加密存库。
> - **合规背景**:覆盖欧盟 GDPR 与加州隐私法对加密通信的要求,映射见第 1 篇第二章。
> - **文档性质**:方案设计与 Java 代码示例。第 2 到 6 篇是各证书的生成参数与示例代码,服务端视角,不涉及设备端实现细节。

## 阅读路径

- **理解方案全貌**:1(先看第二章合规映射与第三章证书层级,再进第四章接口);
- **动手签发**:2(根)→ 3(中间)→ 4(LB 服务端证书);设备侧走 5(密钥与 CSR)→ 6(签发);
- **只关心接口**:1 的第四章,设备端证书申请与续期复用同一接口。

## 证书链与各篇的对应关系

```
根 CA(2) ──签发──> 中间 CA(3) ──┬──签发──> LB 服务端证书(4)   TLS 终结用
                                  └──签发──> 设备证书(6)        mTLS 客户端认证用
设备端(5):本地生成密钥对 → 构造 CSR → 提交申请 → 收到证书
```
