# 中间证书（Intermediate CA）生成说明与 Java 示例

## 一、中间证书所需信息

中间证书由**根证书（Root CA）**私钥签名，用于日常签发设备证书和服务端证书。使用中间证书的目的是**隔离根证书私钥**，根证书私钥离线保存，仅在进行中间 CA 签发时才使用一次。

### 1. Subject 主体信息（Distinguished Name）

| 字段 | OID / 缩写 | 说明 | 示例 |
|:---|:---|:---|:---|
| **Common Name** | `CN` | 证书名称，通常体现用途 | `ipuff.online IoT Intermediate CA` |
| **Organization** | `O` | 组织/公司名，与根证书保持一致 | `ipuff.online Inc.` |
| **Organizational Unit** | `OU` | 部门/单位（可选） | `Security` |
| **Country** | `C` | 国家代码（ISO 3166-1 alpha-2） | `US` |
| **State or Province** | `ST` | 省/州（可选） | `California` |
| **Locality** | `L` | 城市（可选） | `San Francisco` |
| **Email Address** | 无标准 OID | 联系邮箱（可选） | `security@ipuff.online` |

> **注意**：中间证书的 `Subject` 必须与根证书的 `Subject` **不同**（至少 `CN` 不同），否则会导致证书链无法正确构建。

### 2. 密钥算法与长度

| 项目 | 推荐值 | 说明 |
|:---|:---|:---|
| **算法** | RSA | 兼容性最佳，推荐 |
| **密钥长度** | 2048 位 | 满足 NIST / PCI DSS 等主流合规要求 |
| **签名算法** | SHA-256 / SHA-384 | `SHA256withRSA` 为当前主流 |

### 3. 标准扩展（X509v3 Extensions）

| 扩展名 | 必需 | 值 / 说明 |
|:---|:---|:---|
| **BasicConstraints** | 是 | `CA:TRUE`，`pathlen:0`（表示该中间 CA 只能签发终端实体证书，不能再签发下级 CA） |
| **KeyUsage** | 是 | `Certificate Sign`（签发证书）、`CRL Sign`（签发 CRL） |
| **SubjectKeyIdentifier** | 是 | 主体密钥标识符，用于构建证书链时快速匹配 |
| **AuthorityKeyIdentifier** | 是 | 权威密钥标识符，指向签发者（根证书）的公钥标识 |

### 4. 有效期

- 中间证书有效期通常设为 **5 ~ 10 年**
- 应明显短于根证书有效期，以便在必要时进行轮转，而无需更新根证书

### 5. 序列号

- 必须为唯一的正整数
- 建议采用随机大整数，避免与已有证书冲突

## 二、Java 生成中间证书示例

以下示例使用 **BouncyCastle** 库，以**根证书私钥**签名生成中间证书。运行前需先准备好根证书及私钥文件（PEM 格式）。

### Maven 依赖

```xml
<dependency>
    <groupId>org.bouncycastle</groupId>
    <artifactId>bcprov-jdk18on</artifactId>
    <version>1.78</version>
</dependency>
```

### 完整代码

```java
import org.bouncycastle.asn1.x500.X500Name;
import org.bouncycastle.asn1.x509.BasicConstraints;
import org.bouncycastle.asn1.x509.Extension;
import org.bouncycastle.asn1.x509.KeyUsage;
import org.bouncycastle.asn1.x509.SubjectPublicKeyInfo;
import org.bouncycastle.cert.X509v3CertificateBuilder;
import org.bouncycastle.cert.jcajce.JcaX509CertificateConverter;
import org.bouncycastle.cert.jcajce.JcaX509ExtensionUtils;
import org.bouncycastle.openssl.PEMKeyPair;
import org.bouncycastle.openssl.PEMParser;
import org.bouncycastle.openssl.jcajce.JcaPEMKeyConverter;
import org.bouncycastle.operator.ContentSigner;
import org.bouncycastle.operator.jcajce.JcaContentSignerBuilder;
import org.bouncycastle.util.io.pem.PemObject;
import org.bouncycastle.util.io.pem.PemWriter;

import java.io.StringReader;
import java.io.StringWriter;
import java.math.BigInteger;
import java.security.*;
import java.security.cert.X509Certificate;
import java.util.Date;

public class IntermediateCaGenerator {

    /**
     * 根证书 PEM 字符串（仅公钥部分，用于构建证书链和提取 AKI）
     */
    private static final String ROOT_CA_CERT_PEM = """
            -----BEGIN CERTIFICATE-----
            MIIDXTCCAkWgAwIBAgIQC2Z...（请替换为实际根证书内容）
            -----END CERTIFICATE-----
            """;

    /**
     * 根证书私钥 PEM 字符串（用于签名中间证书）
     */
    private static final String ROOT_CA_KEY_PEM = """
            -----BEGIN PRIVATE KEY-----
            MIIEvQIBADANBgkqhkiG9w0B...（请替换为实际根私钥内容）
            -----END PRIVATE KEY-----
            """;

    public static void main(String[] args) throws Exception {
        // 1. 注册 BouncyCastle 安全提供者
        Security.addProvider(new org.bouncycastle.jce.provider.BouncyCastleProvider());

        // 2. 加载根证书和私钥
        X509Certificate rootCert = loadCertificate(ROOT_CA_CERT_PEM);
        PrivateKey rootPrivateKey = loadPrivateKey(ROOT_CA_KEY_PEM);

        // 3. 生成中间 CA 的 RSA 2048 密钥对
        KeyPairGenerator keyGen = KeyPairGenerator.getInstance("RSA", "BC");
        keyGen.initialize(2048, new SecureRandom());
        KeyPair keyPair = keyGen.generateKeyPair();

        // 4. 构建 Issuer（根证书 Subject）和 Subject（中间证书 Subject）
        X500Name issuer = new X500Name(rootCert.getSubjectX500Principal().getName());
        X500Name subject = new X500Name(
                "C=US, ST=California, L=San Francisco, O=ipuff.online Inc., OU=Security, CN=ipuff.online IoT Intermediate CA"
        );

        // 5. 有效期：10 年
        long now = System.currentTimeMillis();
        Date notBefore = new Date(now);
        Date notAfter = new Date(now + 10L * 365 * 24 * 60 * 60 * 1000);

        // 6. 随机序列号
        BigInteger serialNumber = new BigInteger(160, new SecureRandom());

        // 7. 构造证书 Builder
        SubjectPublicKeyInfo publicKeyInfo = SubjectPublicKeyInfo.getInstance(
                keyPair.getPublic().getEncoded()
        );
        X509v3CertificateBuilder certBuilder = new X509v3CertificateBuilder(
                issuer,           // issuer = 根证书 Subject
                serialNumber,
                notBefore,
                notAfter,
                subject,          // subject = 中间证书 Subject
                publicKeyInfo
        );

        // 8. 添加扩展
        JcaX509ExtensionUtils extUtils = new JcaX509ExtensionUtils();

        // SubjectKeyIdentifier
        certBuilder.addExtension(
                Extension.subjectKeyIdentifier,
                false,
                extUtils.createSubjectKeyIdentifier(keyPair.getPublic())
        );

        // AuthorityKeyIdentifier（指向根证书的公钥）
        certBuilder.addExtension(
                Extension.authorityKeyIdentifier,
                false,
                extUtils.createAuthorityKeyIdentifier(rootCert)
        );

        // BasicConstraints: CA = true, pathlen = 0（只能签发终端实体证书）
        certBuilder.addExtension(
                Extension.basicConstraints,
                true,
                new BasicConstraints(0)
        );

        // KeyUsage: Certificate Sign + CRL Sign
        certBuilder.addExtension(
                Extension.keyUsage,
                true,
                new KeyUsage(KeyUsage.keyCertSign | KeyUsage.cRLSign)
        );

        // 9. 使用根证书私钥签名
        ContentSigner signer = new JcaContentSignerBuilder("SHA256withRSA")
                .setProvider("BC")
                .build(rootPrivateKey);

        X509Certificate cert = new JcaX509CertificateConverter()
                .setProvider("BC")
                .getCertificate(certBuilder.build(signer));

        // 10. 输出 PEM
        System.out.println("========== 中间证书 (Intermediate CA) ==========");
        System.out.println(toPem("CERTIFICATE", cert.getEncoded()));

        System.out.println("========== 中间 CA 私钥 (Private Key) ==========");
        System.out.println(toPem("PRIVATE KEY", keyPair.getPrivate().getEncoded()));

        System.out.println("========== 证书链验证 ==========");
        cert.verify(rootCert.getPublicKey());
        System.out.println("证书链验证通过：中间证书已由根证书正确签名。");
    }

    private static X509Certificate loadCertificate(String pem) throws Exception {
        try (PEMParser parser = new PEMParser(new StringReader(pem))) {
            Object obj = parser.readObject();
            return new JcaX509CertificateConverter()
                    .setProvider("BC")
                    .getCertificate((org.bouncycastle.cert.X509CertificateHolder) obj);
        }
    }

    private static PrivateKey loadPrivateKey(String pem) throws Exception {
        try (PEMParser parser = new PEMParser(new StringReader(pem))) {
            Object obj = parser.readObject();
            if (obj instanceof PEMKeyPair) {
                return new JcaPEMKeyConverter()
                        .setProvider("BC")
                        .getKeyPair((PEMKeyPair) obj)
                        .getPrivate();
            } else if (obj instanceof PrivateKey) {
                return (PrivateKey) obj;
            } else {
                throw new IllegalArgumentException("不支持的私钥格式: " + obj.getClass());
            }
        }
    }

    private static String toPem(String type, byte[] data) throws Exception {
        StringWriter sw = new StringWriter();
        try (PemWriter pw = new PemWriter(sw)) {
            pw.writeObject(new PemObject(type, data));
        }
        return sw.toString();
    }
}
```

### 运行结果说明

程序输出两段 PEM：

1. **`CERTIFICATE`** —— 中间证书公钥，需下发到设备端（与根证书共同构建完整信任链）并配置到 LB
2. **`PRIVATE KEY`** —— 中间 CA 私钥，**部署到 RA 服务端**，用于签发设备证书和服务端证书

### 安全建议

- 中间 CA 私钥可部署在**线上 RA 服务端**，但仍建议存储在加密数据库或 HSM 中
- 根证书私钥**仅在本代码运行时使用一次**，运行完成后应立即从运行环境中移除
- 建议定期对中间 CA 进行轮转（如每 5 年），而无需触碰根证书
- 签发终端实体证书时，设备端必须同时持有**根证书 + 中间证书**才能构建完整的信任链
