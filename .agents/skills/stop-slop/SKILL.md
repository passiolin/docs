# Stop Slop(去 AI 腔)

中文本地化版:基于上游 commit `8da1f03`(2026-10)翻译并按中文语境改写,英文原版见[上游仓库](https://github.com/hardikpandya/stop-slop);MIT,署名保留。与本仓库 writing-style 规范冲突时以 writing-style 为准,裁决见文末。

消除文字中可预测的 AI 写作痕迹。

## 核心规则

1. **删填充语。**清嗓式开场、表演性强调、修饰性副词一律删,见 [references/phrases.md](references/phrases.md)。
2. **拆公式化结构。**二元对比、否定铺垫、戏剧化断句、空转设问、强行拟人都不要,见 [references/structures.md](references/structures.md)。
3. **用主动语态。**每句话要有具体的行为者在做事;不用被动句,不让无生命对象做人的动作("抱怨化为了修复")。
4. **写具体。**不许空泛断言("原因主要是结构性的"),写出那个具体的东西;不用"所有/永远/从不"这类懒极端词撑场面。
5. **把读者拉进现场。**不用旁白解说腔;具体胜过抽象,在场胜过俯视。
6. **变换节奏。**长短句交替,两项胜过三项,段落结尾不重样。
7. **信任读者。**直接陈述事实,不加软化、辩解、手把手。
8. **删金句。**一句话听着像能截图转发的,重写。

## 交付前速查

- 有修饰性副词?删。
- 被动句?找到行为者,放到主语位。
- 无生命对象做人的动作("决策应运而生")?点名人。
- 自问自答开场?删问,直接给答。
- "事情是这样的"式清嗓?切到正题。
- "不是 X,而是 Y"?直接说 Y。
- 连续三句等长?拆一句。
- 每段结尾都甩短句?变化结尾。
- 空泛断言("影响深远")?写出那个具体影响。
- 旁白解说("没有人设计过这一切")?把读者放进现场。
- 元评论("本文将介绍…")?删,让内容自己走。

## 评分

每个维度打 1–10 分:

| 维度 | 问题 |
|------|------|
| 直接 | 陈述事实,还是宣布姿态? |
| 节奏 | 长短有变化,还是节拍器? |
| 信任 | 尊重读者智力,还是手把手? |
| 人味 | 像人说话,还是像播报? |
| 密度 | 还有可删的吗? |

低于 35/50:重写。自评会虚高,"密度"一项从严。

## 本仓库适配(writing-style 冲突裁决)

- **人称**:部署手册、巡检报告禁"你",规则 5 的"读者进现场"只适用于教程类;人称细则以 writing-style 为准。
- **副词**:承重副词("约/仅/才/几乎")保留,只删修饰性的("非常/真的/实际上")。
- **破折号**:——是中文固有标点,不禁;英文场景才执行上游的禁破折号规则。
- **判别尺**:结构类目与 writing-style「句式类 AI 腔」表同一套病,共用一把尺——换成最平的说法而信息无损,即装饰,删。
