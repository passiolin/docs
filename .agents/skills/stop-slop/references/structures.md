# 应避免的结构(中文版)

基于上游 structures.md(commit `8da1f03`)本地化:句式换为中文对应物,判别与 writing-style「句式类 AI 腔」表共用一把尺——换成最平的说法而信息无损,即装饰,删。

## 二元对比

制造假转折。直接陈述论点。

| 句式 | 毛病 |
|------|------|
| "不是 X,而是 Y" | 预告式反转 |
| "X 不是问题,Y 才是" | 公式化翻案 |
| "答案不是 X,是 Y" | 可预测的急转弯 |
| "看似 X,实则 Y" | 铺垫揭底套路 |
| "与其说是 X,不如说是 Y" | 机械对比 |
| "不仅是 X,更是 Y" | 加码式对冲 |

判别(中文语境放宽):对比**两端都带事实**才合法——"瓶颈不是容量,是磁头"是信息;"这不是一次故障,而是一次校准"一端为空,删,直接陈述后半句。

## 否定铺垫

先连排"不是什么",再揭晓"是什么"。用否定攒戏剧感。

| 句式 | 毛病 |
|------|------|
| "不是 A,不是 B,而是 C" | 否定式起跑 |
| "它既不是工具,也不是框架,而是一种方法论" | 同构,换个时态 |

改法:直接说 C。读者不需要助跑。

## 戏剧化断句

为强调而砍碎句子,读起来像人造的深刻。

| 句式 | 毛病 |
|------|------|
| "X。就这么简单。" | 表演式简洁 |
| "快。好。省。只能选两个。" | 短句轰炸 |
| "记住三个词:快、稳、省。" | 人造揭底 |

改法:完整句。信内容,别信姿态。

## 空转设问

宣布洞见而不交付洞见。

| 句式 | 毛病 |
|------|------|
| "想一想:" / "试想一下:" | 居高临下的提示 |
| "如果换个角度呢?" | 苏格拉底式摆姿势 |
| "而这没什么不对。" | 多余的许可 |

改法:直接给论点。结论留给读者自己下的空间。

## 公式化构造

| 句式 | 毛病 |
|------|------|
| "与其等到 X,不如现在就 Y" | 叙事模板 |
| 绕着说"X 还没有达到 Y 的状态" | 直接说"X 不行" |

## 强行拟人

无生命对象做人的动作。AI 爱用,因为这样可以不点名行为者。

| 句式 | 毛病 |
|------|------|
| "抱怨最终化为了修复" | 抱怨什么都没做,是人修的 |
| "决策应运而生" | 决策不会自己长出来,是人拍的板 |
| "文化在悄然改变" | 文化不会自己变,是人改了行为 |
| "数据告诉我们" | 数据躺在那,是人读了它得出结论 |
| "市场会奖励…" | 市场不发奖,是买家在付钱 |
| "需求被满足了" | 谁满足的?写谁 |

改法:点名人。"团队当周就修了"胜过"抱怨化为了修复";找不到具体人,用"你"把读者放进现场(教程类;部署手册的人称限制见 SKILL.md 适配节)。

## 旁白解说腔

悬在场景上空,而不是把读者放进场景。

| 句式 | 毛病 |
|------|------|
| "没有人设计过这一切" | 无主体的悬空观察 |
| "人们往往会…" | 沙发社会学家 |
| "这正是为什么…" | 讲师腔 |

改法:把读者放进现场。"你不会某天坐下来决定…"胜过"没有人设计过这一切"。

## 被动句藏主体

被动句 hides 行为者,抽干句子能量。

| 句式 | 改法 |
|------|------|
| "X 被创建了" | 写谁创建 |
| "普遍认为" | 写谁认为 |
| "决策已经作出" | 写谁决策 |

判别:能点名而不点名,即违规;行为者确实不可考("初始化被跳过")可保留。

## 句首套路

中文没有 Wh- 开头的问题,对应的坑:

| 句式 | 改法 |
|------|------|
| 段落以"那么,""所以,"开头 | 以内容开头 |
| 自问自答开场("为什么?因为…") | 删问,直接给答 |
| 空转的"首先…其次…最后" | 有实内容的编号合法(writing-style 豁免条款) |

## 节奏套路

| 句式 | 改法 |
|------|------|
| 三连排比 | 两项或一项 |
| 每段结尾都甩短句 | 变化结尾 |
| 短句连击 | 别堆 |
| 破折号(——) | 中文固有标点,不禁;英文场景才执行上游禁令 |

## 用词套路

| 句式 | 毛病 |
|------|------|
| 懒极端词:所有、永远、从不、没人、大家 | 概括断言里撑假权威;可数范围内的"所有"合法("池里所有 VM") |
| 修饰性副词 | 空心强调,见 [phrases.md](phrases.md) |
