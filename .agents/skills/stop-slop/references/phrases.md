# 应删词句(中文版)

基于上游 phrases.md(commit `8da1f03`)本地化:中文 AI 腔为主列表,英文原版每类留一行对照。

## 清嗓式开场

先报场再进内容。删掉报场,直接说。

- "事情是这样的" / "事情要从…说起"
- "说到底" / "归根结底"
- "我们不得不承认" / "坦白讲" / "说句实话"
- "残酷的真相是" / "扎心的真相是"
- "你可能不知道" / "你有没有想过"
- "事实证明" (开头处,后文无实测支撑时)

凡"事情是这样的/要从…说起"式构造,都是正题前的清嗓。删掉,直接说正题。
英文原版对应:Here's the thing: / It turns out / The truth is, / Let me be clear / Can we talk about…

## 强调拐杖

不携带信息。删。

- "就这么简单。" / "就是这样。" / "仅此而已。"
- "细品。" / "品,你细品。"
- "数据不会说谎。"
- "划重点:" / "敲黑板:"
- "这才是关键。"

英文原版对应:Full stop. / Let that sink in. / Make no mistake / Here's why that matters

## 黑话替换

换成平话。

| 避免 | 改用 |
|------|------|
| 赋能 | 帮助、支撑 |
| 抓手 | 手段、切入点 |
| 闭环 | 走完整条流程、收口 |
| 沉淀 | 积累、留存 |
| 底层逻辑 | 原理 |
| 顶层设计 | 整体规划 |
| 打法 | 做法 |
| 组合拳 | 多项措施 |
| 护城河 | 竞争优势 |
| 降维打击 | 代差优势 |
| 颗粒度 | 粒度 |
| 心智 | 认知、印象 |
| 引爆 | 带动 |

英文原版对应:navigate→handle / unpack→explain / landscape→situation / game-changer→significant / deep dive→analysis / circle back→revisit

## 副词

修饰性副词删;**承重副词不在禁列**——"约、近、仅、才、几乎"承担数量与范围语义,是技术文档的骨头。

删这些:

- "非常" "十分" "极其" "真的" "简直"
- "实际上" "其实"(推论义;"实际上有 3 台"这类计数义不算)
- "彻底地" "毫无疑问" "本质上" "归根结底"(修饰用法)

英文原版对应(-ly 词全禁):really / just / literally / genuinely / honestly / simply / actually / crucially

配套填充句:"在当今…的背景下" "归根结底" "当谈到…时" "众所周知" "值得注意的是"

## 元评论

自己评论自己文章结构的插嘴。文章要走,不要报站。

- "废话不多说" / "直接上干货"
- "接下来我们来看" / "下面进入…环节"
- "温馨提示:" / "小贴士:"
- "剧透一下:" / "重点来了:"
- "本文将介绍…" / "本节先…"(writing-style 黑名单已有)

英文原版对应:Hint: / Plot twist: / The rest of this essay explains… / As we'll see…

## 表演性强调

假亲密、造真诚:

- "相信我" / "我保证"
- "悄悄说" / "你品"
- "细思极恐" / "耐人寻味的是"

英文原版对应:I promise / creeps in

## 告而不 show

宣布难度或意义,而不是把它演示出来:

- "这真的很难" / "复杂度超乎想象"
- "这一步至关重要"(不写为什么)
- "效果拔群" / "体验极佳"

英文原版对应:This is genuinely hard / actually matters

## 空泛断言

宣布重要而不点名具体之物。删,或换成那个具体之物:

- "原因主要是结构性的"
- "影响深远" / "意义重大"
- "问题很复杂"
- "风险不容忽视"

判别:一句话说某事重要/深刻/复杂,却不给出那个具体的东西——删,或把具体写出来。
